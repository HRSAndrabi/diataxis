# Privacy Policy

Last updated: 2026-05-08

Diataxis Documentation is a Claude Code plugin that helps survey, plan, and write project documentation using the Diataxis framework.

## Data Collection

This plugin does not collect, store, sell, or transmit personal information to the plugin author.

The plugin runs inside Claude Code and operates on the files in the project where you invoke it. It may read project files and documentation so it can classify existing documentation, identify gaps, and draft new documents. Any information processed by Claude Code is handled by Claude Code and Anthropic according to their applicable terms and privacy policies.

## Data Use

The plugin uses local project context only to:

- Survey existing documentation.
- Classify documentation using the Diataxis framework.
- Propose documentation improvements.
- Write approved documentation files.

The plugin does not include analytics, telemetry, advertising, or tracking code.

## Data Sharing

The plugin author does not receive or share any project content, personal information, or usage data from this plugin.

If you use Claude Code or related Anthropic services, data may be processed by those services according to their own policies.

## User Control

The plugin is designed to ask for approval before writing documentation. You control which files are created or changed through your Claude Code session.
